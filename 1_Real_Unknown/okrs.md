# 🏆 Objectives and Key Results (OKRs)

> **Stage 1: Real Unknown** — Define measurable and time-bound goals for the project.

---

## 🎯 Objective 1: Repurpose YouTube content into multi-channel outreach automatically

*Build a marketing application, buffer, that turns each YouTube video into ready-to-use posts across our other outreach channels.*

- **KR 1.1:** Ingest metadata + transcript for a given YouTube video (from our channel) into the system.
- **KR 1.2:** Generate a draft post for each of the 6 target channels (LinkedIn, X.com, Reddit, Skool, YouTube, Email) from a single source video.
- **KR 1.3:** Human review/edit step exists before anything is scheduled or posted (no blind auto-posting in v1).

---

## 🎯 Objective 2: Create posts for social media channels (key result of this project)

*The concrete, measurable output of this project is the ability to create real, channel-ready posts.*

- **KR 2.1:** Successfully create at least one real draft post per channel type from a real source video.
- **KR 2.2:** Each generated post respects the target channel's format constraints (character limits, tone, structure — e.g. X.com length limits, Reddit self-post/community norms, LinkedIn long-form style).
